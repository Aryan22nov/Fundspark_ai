## Techspark AI (merged)

**AI-Powered Startup Accelerator for Founders & Investors**

### Product Vision
Techspark AI helps early-stage startups and investors with:
- Pitch deck analysis
- Startup scoring
- Customer insight
- Competitor mapping
- Investor matching
- Business report generation
- Marketing & content suggestions

### Core Features (high level)
- Startup Creator (multi-step forms, AI autofill)
- Pitch Deck Analyzer (PDF/text analysis)
- Startup Score Engine
- Customer Analysis and ICP generation
- Competitor Analyzer and comparisons
- Investor Matcher and pitch personalization
- Content generation (taglines, posts, emails)
- Recommendation engine for next steps

### Quick Start
1. npm install
2. Add your Gemini API key to .env as VITE_GEMINI_API_KEY if needed
3. npm run dev for local development
